# Reporting Engine UI Walkthrough

## Page Purpose
Centralized reporting hub for generating pre-built and custom reports on teacher statistics, transfers, certifications, and zone-level analytics. Supports PDF and Excel export formats.

## User Flow
1. **Landing View**: Reports tab showing:
   - Stats cards: Total Templates, Recent Reports, This Month count, Favorites
   - Two tabs: Report Library | Recent Reports

2. **Report Library**: Grid of pre-built report templates:
   - Teacher Census Report
   - Transfer Statistics
   - Certification Status
   - Zone Statistics
   - School Staffing Report
   - Document Processing Summary

3. **Template Cards**: Each displays:
   - Icon with gradient background
   - Report name and description
   - Frequency badge (Weekly/Monthly/Quarterly)
   - Field tags (Zone, School, Gender, etc.)
   - Last generated date
   - Hover reveals "Generate" button

4. **Custom Report Builder**: Dialog with:
   - Report type selection (custom census, transfer, certification, zone)
   - Date range pickers (From/To)
   - Zone multi-select checkboxes
   - Field selection checkboxes (for custom reports)
   - Options: Include Charts, Include Summary
   - Output format: PDF or Excel

5. **Generation**: Click Generate:
   - Loading spinner while processing
   - Report added to Recent Reports list
   - Download or print options available

6. **Recent Reports Tab**: List view showing:
   - Report name with template source
   - Generated timestamp
   - Generated by user
   - Format badge (PDF/Excel)
   - File size
   - Quick actions: View, Download, Print

## Components Used
- `Card`: Template cards, stats cards, recent reports container
- `Dialog`: Report Builder modal
- `Tabs` (TabsList, TabsTrigger, TabsContent): Library/Recent toggle
- `Select`: Report type dropdown
- `Input`: Date pickers
- `Checkbox`: Zone selection, field selection, options
- `Button`: Format toggle (PDF/Excel), Generate, actions
- `Badge`: Frequency labels, format badges
- `ScrollArea`: Field selection list
- `Label`: Form field labels
- **Lucide Icons**: BarChart3, FileText, Download, Printer, etc.

## Pre-Built Report Templates

| Report | Frequency | Key Fields |
|--------|-----------|------------|
| Teacher Census | Monthly | Zone, School, Gender, Qualification, Years of Service |
| Transfer Statistics | Weekly | From Zone, To Zone, Status, Date Range |
| Certification Status | Monthly | Status, Expiry Period, Zone, Qualification |
| Zone Statistics | Quarterly | Zone, School Type, Teacher Count, Student Ratio |

## Intended Logic Flow

### Template Selection
```
1. User clicks template card
2. openReportBuilder(template) called
3. Pre-populate builder with template defaults
4. Open Dialog in generate mode
```

### Custom Report Building
```
1. User clicks "Custom Report" button
2. openReportBuilder() with no template
3. Show full field selection options
4. User selects report type, date range, zones, fields
5. Generate custom query parameters
```

### Report Generation
```
1. Set isGenerating = true
2. Collect all builder parameters
3. Call Electron IPC: generateReport(params)
4. Electron main process:
   a. Query IndexedDB with filters
   b. Generate PDF via jsPDF or Excel via xlsx
   c. Save to app data folder
   d. Return file path
5. Add to recentReports list
6. Set isGenerating = false
7. Close dialog
8. Option to auto-open file
```

### Recent Reports
```
1. Load from IndexedDB on mount
2. Sort by generatedAt descending
3. Show last 20 reports
4. View/Download/Print trigger Electron file handlers
```

### Export Formats
```
PDF:
- Uses jsPDF or pdfmake
- Includes PPSMB letterhead
- Charts rendered as images
- Tables auto-paginated

Excel:
- Uses xlsx library
- Separate sheets for data and summary
- Charts as Excel native charts
- Formulas for totals
```
